# Unity Narrative System - Integration Documentation

## 📋 Documentation Overview

This documentation package provides everything needed to integrate the Unity Narrative System into other Unity projects. The system is a flexible, event-driven framework for creating branching narrative experiences, featuring a powerful visual editor and AI-assisted content creation tools.
